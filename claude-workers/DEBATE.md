# Debate Protocol

## Purpose

Two planners with different perspectives analyze the same problem and debate to find the optimal solution.

## Process

### Phase 1: Independent Planning

Each planner creates their own implementation plan without seeing the other's work.

### Phase 2: Cross-Review

Each planner reviews the other's plan and identifies:

- Strengths they agree with
- Weaknesses or gaps
- Alternative approaches
- Missing considerations

### Phase 3: Debate

Planners engage in structured debate:

1. Present key disagreements
2. Argue for their preferred approach with evidence
3. Acknowledge valid points from the other side
4. Find common ground

### Phase 4: Synthesis

Combine the best elements from both plans into a unified approach that:

- Takes the strongest technical decisions from each
- Addresses concerns raised by both sides
- Creates a coherent, actionable plan

## Debate Rules

- Focus on technical merit, not personality
- Support arguments with concrete reasoning
- Be willing to change position given good evidence
- Prioritize the best outcome over being right
